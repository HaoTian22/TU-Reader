# NFC 交通卡读取器 
⚠️作者并不熟悉Android App开发，顶多能看懂一点代码，99%都是Vibe-Coding出来的

这是基于公开交通卡协议文档（NFC Wiki 智能卡手册）搭建的最小可用（MVP）Android 项目，
用于替代已停更的"读卡识途"App 的核心功能：读取交通卡余额与交易记录。

## 当前支持范围（第一版）

- 交通联合卡 (T-Union) 电子钱包应用

## 数据来源
