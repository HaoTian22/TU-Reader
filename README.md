## 核心原理

### 数据来源

卡种 AID、SFI、文件结构均来自 NFC Wiki 智能卡手册（wiki.nfc.im/books/智能卡手册），
APDU 命令格式参考 ISO/IEC 7816-4 标准及 Android 官方 NFC/HCE 开发文档。

二、各卡型读取序列（完整）

1. 通用 TU / 交通联合（d() 魔数通过，或 SELECT f850o 成功）

SFI 0x04 (00 B0 84 00 3C, 60B)  卡号[0..8)、有效期[28..32)、魔数校验
SFI 0x05 (00 B0 85 00 20, 32B)  备用、余额兜底[6..9)
SELECT 1001 + BALANCE CHECK → 余额
SFI 0x15 (00 B0 95 00 1E, 30B)  卡信息
SFI 0x17 (00 B0 97 00 3C, 60B)  TU17 城市信息
SFI 0x19 rec6 (00 B2 06 C8 30, 48B)  杭州/宁波 POS
SFI 0x18 rec1..31 (00 B2 <r> C4 17, 23B)  交易
SFI 0x06 rec1..31 (00 B2 <r> 34 17, 23B)  CU/TFT 附加交易
TU交易
- 北京(1000)：SELECT BMAC → SFI 0x03 rec1 (00 B2 01 1C 32, 50B)；SELECT f850o → SFI 0x08 rec1 (00 B2 01 44 32, 50B)
- 上海(2900)：SFI 0x11 rec1/2 (16B)、SFI 0x14 rec4/5 (16B)、SFI 0x17 rec2 (00 B2 02 BC 10, 16B)、SFI 0x10 rec2 (16B)
- 南京(3010)：SFI 0x07 rec1/2 (00 B2 01/02 3C 40, 64B)
- 常州(3020)：SFI 0x07 rec1 (00 B2 01 3C 10, 16B)
- 苏州(3050)：SFI 0x19 rec1 (00 B2 01 CC 32, 50B)
- 广州(5810)/佛山(5880)：SFI 0x19 rec1 (00 B2 01 CC 30, 48B) 折扣统计+政策判定
- 全部城市：SFI 0x1E rec1..31 (00 B2 <r> F4 30, 48B) 交易 txTUResult —— 这就是"交联的 0x1E"

6. 住建部 CU（SELECT f849n 成功）

g() + f() + e(196) → SFI 0x18
e(132) → SFI 0x10
cdCUCity≠2000: e(52) → SFI 0x06；上海: e(212) → SFI 0x1A

一句话：卡信息各读各的（TU 0x04/0x05/0x17、YCT 0x15、深圳 0x15、苏州 0x06、天津 0x1A）；统计/折扣按城市分流（YCT 0x08、北京 0x03/0x08、苏州 0x19、天津 0x1A、杭州 0x17）；交易统一 23B 主 SFI 0x18 + 各卡附加（CU 0x10/0x06/0x1A、天津 0x09），交联 TU 专属 48B 在 SFI 0x1E。
